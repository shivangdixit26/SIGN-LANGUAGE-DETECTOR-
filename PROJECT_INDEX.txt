```
Status: Reads kaggle.json credentials ✓
```

```
Status: Processes each image independently ✓
```

```
Optimization: L2 regularization + Dropout
```

**Real-time testing on PC webcam**
```
Status: Interactive live feed ✓
Uses: OpenCV + MediaPipe + Trained model
Displays: Predictions, confidence, FPS

Optimization: Frame skipping for performance
```

**Quantizes Keras model for edge deployment**

## 💡 Key Design Decisions

### Why MediaPipe?
- Robust hand detection and landmark extraction
- Works great with constrained hand angles
- Ready-to-use 21-point hand model
- ARM optimized for Raspberry Pi

### Why Lightweight DNN?
- Only ~10K parameters = 200KB model
- Trains in <15 minutes on CPU
- Quantizes to 15KB for edge deployment
- 30-40ms inference (suitable for real-time)

### Why TFLite?
- 10x smaller than full TensorFlow
- ARM optimizations (NEON instructions)
- Quantization reduces size 10x more
- Battle-tested on millions of edge devices

### Why Temporal Smoothing?
- Reduces jitter in predictions
- Voting over 3-5 frames stabilizes output
- Minimal latency cost (3-5 frame delay)
- Improves perceived accuracy

## 🛠️ Maintenance & Updates

### If Updating MediaPipe
```bash
pip install --upgrade mediapipe
# Rerun 2_extract_features.py and 3_train_model.py
```

### If Wanting Better Accuracy
```bash
# Modify 3_train_model.py:
EPOCHS = 200          # Increase training
LEARNING_RATE = 0.0005  # Slower, more stable
BATCH_SIZE = 16       # Smaller batches
# Then retrain: python 3_train_model.py
```

### If Deploying to Multiple Pis
```bash
# Copy models folder to each Pi:
scp models/model.tflite pi1@host1:~/sign
scp models/model.tflite pi2@host2:~/sign
# Each runs: python 6_pi_inference.py
```
